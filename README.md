# 🌦️ Weather Web App

A responsive Weather Web Application that allows users to search for any city and get real-time weather information using the WeatherAPI.com API.

## 🚀 Features

- Search weather by city name.
- Display current temperature.
- Show weather conditions.
- Display humidity and wind speed.
- Fetch real-time weather information.
- Responsive user interface.

## 🛠️ Technologies Used

**Frontend:**
- React.js
- JavaScript
- HTML5
- CSS3
- Vite

**Backend:**
- Node.js
- Express.js
- Axios

**Database:**
- MongoDB

**API:**
- WeatherAPI.com

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd weather-app
```

### 3. Install dependencies

Navigate to the frontend and backend folders separately and run:

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the backend folder and add:

```env
API_KEY=your_weatherapi_key
```

Add other required environment variables if your backend uses them.

### 5. Run the Application

Start the backend:

```bash
npm start
```

Start the frontend:

```bash
npm run dev
```

## 🌐 Weather API

This project uses [WeatherAPI.com](https://www.weatherapi.com/) to fetch real-time weather information.
